# 🍣 스시 마스터 (Sushi Master)

> **신선한 재료로 손님들의 주문을 맞춰 완성하는 스시 타이쿤 웹 게임!**

## 🎮 게임 소개
- **플레이 링크**: [https://jmwoo711-ctrl.github.io/sushi_cooker/](https://jmwoo711-ctrl.github.io/sushi_cooker/)
- 손님들의 말풍선 주문에 맞춰 초밥을 쥐고 서빙하여 최고 매출과 콤보를 달성하세요!
- "와사비 빼주세요!" 같은 섬세한 손님 취향을 반영해야 합니다.

## 🕹️ 조작 방법
- **마우스 & 터치**: 화면의 재료와 서빙 버튼을 직접 클릭/터치
- **키보드 단축키**:
  - `1`: 샤리 (밥)
  - `2`: 생와사비
  - `Q`: 생연어
  - `W`: 참치(마구로)
  - `E`: 초새우
  - `R`: 계란말이
  - `T`: 양념 장어
  - `Y`: 날치알 군함말이
  - `Space` / `Enter`: 손님에게 서빙
  - `X` / `Delete`: 도마 비우기

## 🛠️ 기술 스택
- **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Audio Engine**: Web Audio API (외부 에셋 없이 실시간 합성된 레트로 효과음 및 BGM)
- **Deployment**: GitHub Pages
